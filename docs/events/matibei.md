# 码蹄杯全国大学生程序设计大赛

<EventDetails />

## 名称与收录范围

官方题集页面使用“码蹄杯全国大学生程序设计大赛”。页面关于竞赛榜单的说明特别指向职业院校赛道，不能据此宣称本科赛道或本校具有相同认定。题集年份也不等于开放报名年份。

依据：码蹄集官方历年题集与赛事简介。

## 准备建议

先用公开题集了解难度，再确认当届本科、职业院校等赛道的适用对象。公开题目适合训练，但不是报名入口。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
