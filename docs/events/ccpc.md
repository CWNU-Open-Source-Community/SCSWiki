# 中国大学生程序设计竞赛（CCPC）

面向大学生的程序设计赛事，适合持续进行算法训练与团队配合练习。

<EventDetails />

## 比赛简介

中国大学生程序设计竞赛（CCPC）是国内的大学生程序设计赛事。其经典团队赛同样强调限时解题与协作：队员共同分析题目、组织算法并提交程序接受评测。

CCPC 与 ICPC 是不同的赛事体系。两者可以共享不少算法训练方法，但赛站报名、队伍资格、名额和晋级规则不能相互套用。

## 适合谁参与

适合希望参与国内团队算法竞赛、已有一定独立解题能力的同学。还在学习阶段时，可以先做往届题和模拟赛，再了解学校队伍的训练与选拔安排。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                       |
| ---------- | -------------------------------------------------------------- |
| 题目求解   | 把文字描述转化为数学或数据结构模型，评估算法是否满足数据规模。 |
| 团队比赛   | 在经典三人共用设备的形式下，协调推导、编码与查错。             |
| 赛事体系   | 关注具体届次和赛站，区分网络赛、区域赛事与总决赛等不同安排。   |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 选一套有公开题解的往届题，先限时尝试，再根据未完成题查漏补缺。
2. 练习向队友解释复杂度、正确性及边界条件，而不只报出算法名称。
3. 模拟比赛时记录换机与错误提交原因，形成可重复执行的沟通习惯。
4. 赛后补齐最接近完成的题，再安排新知识专题，避免只积累零散模板。

## 常见问题

### 能直接沿用 ICPC 的报名资格吗？

不能。即使训练方式相近，CCPC 的届次和赛站规定仍需单独核实。

### 找不到队友时怎么准备？

先完成个人基础训练和题解记录，参加校内公开训练或交流，再寻找时间安排与目标相近的伙伴。

## 参与总结

CCPC 可以作为持续算法训练的具体目标。对新队伍而言，稳定完成擅长的题、减少沟通失误，往往比临赛堆积大量高级算法更实际。
