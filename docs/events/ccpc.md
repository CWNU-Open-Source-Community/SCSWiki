# 中国大学生程序设计竞赛（CCPC）

面向大学生的程序设计赛事，适合持续进行算法训练与团队配合练习。

<EventDetails />

## 名称与收录范围

官方名称为中国大学生程序设计竞赛，英文为 China Collegiate Programming Contest。CCPC 与 ICPC 是不同赛事；网络赛、分站赛与总决赛属于赛事体系中的不同阶段或赛站，不在目录中重复计数。

依据：[CCPC 官方报名与赛事平台](https://signup.ccpc.io/)。

## 准备建议

根据当届赛站要求核对资格与名额，使用公开题目开展限时训练。校内选拔、名额和认定只以本校通知为准。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
