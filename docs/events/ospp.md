# 点亮计划-开源之夏

<EventDetails />

## 名称与收录范围

2026 年官方名称为“点亮计划-开源之夏”，聚焦 RISC-V 生态基础软件。FAQ 明确项目与开发阶段滚动开放，并提供经典模式与学生领航模式，不再沿用统一暑期时间表。学生须年满 18 周岁，且开发期间保持符合要求的在籍身份。

依据：点亮计划-开源之夏 2026 官方 FAQ。

## 准备建议

先选择匹配自身能力的项目，阅读学生指南与项目交付标准，再尝试运行代码。滚动开放不代表任意项目随时有名额，申请窗口需逐项查看。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。
