# 点亮计划-开源之夏

围绕 RISC-V 基础软件生态参与开源项目，按项目节奏开展持续开发。

<EventDetails />

## 名称与收录范围

2026 年官方名称为“点亮计划-开源之夏”，聚焦 RISC-V 生态基础软件。FAQ 明确项目与开发阶段滚动开放，并提供经典模式与学生领航模式，不再沿用统一暑期时间表。学生须年满 18 周岁，且开发期间保持符合要求的在籍身份。

依据：[点亮计划-开源之夏 2026 官方 FAQ](https://docs2026.summer.ospp.ac.cn/help/FAQ)。

## 准备建议

先选择匹配自身能力的项目，阅读学生指南与项目交付标准，再尝试运行代码。滚动开放不代表任意项目随时有名额，申请窗口需逐项查看。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
