# 点亮计划-开源之夏

围绕 RISC-V 基础软件生态参与开源项目，按项目节奏开展持续开发。

<EventDetails />

## 活动简介

点亮计划-开源之夏通过开源社区项目和导师指导，让学生参与真实软件开发。2026 年官方 FAQ 介绍了围绕 RISC-V 等基础软件方向的安排，并区分经典模式与学生领航模式，不能完全沿用往年单一暑期日程。

对申请者而言，关键是理解一个项目的实际问题、技术要求和可交付成果，再根据自己的基础安排开发计划。导师可以提供指导，但贡献仍需要本人持续实现、验证和沟通。

## 适合谁参与

适合希望接触真实代码库、能够持续投入项目开发的同学。参赛资格应看当届学生要求；技术准备则要围绕具体社区和任务进行。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                 |
| ---------- | -------------------------------------------------------- |
| 选择项目   | 阅读任务说明、代码库与前置知识，判断兴趣和能力是否匹配。 |
| 申请与沟通 | 通过运行项目、复现问题和讨论方案，形成有依据的计划。     |
| 开发与评估 | 按项目安排交付阶段成果，响应评审并整理最终贡献。         |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 选择少量真正感兴趣的项目，先独立完成环境搭建。
2. 阅读贡献指南和相关模块，带着已尝试的过程向社区提出具体问题。
3. 把方案拆成可检查的里程碑，说明风险、测试和可用时间。
4. 开发中及时汇报进展与阻塞，保留提交、讨论和验证记录。

## 常见问题

### 只在申请时写一份提案就够了吗？

一份可信的提案通常需要对项目已有了解。先运行代码和讨论范围，有助于判断计划是否可行。

### 今年仍是往年固定的暑期流程吗？

2026 年 FAQ 已调整项目模式与安排，应按所选项目和当届阶段说明核对，不能照搬旧时间表。

## 参与总结

开源之夏适合从“独立写代码”走向“在社区中交付代码”。理解需求、回应评审和维护可复现成果，是与编码同样重要的能力。
