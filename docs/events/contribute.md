# 推荐活动与补充经验

[← 返回活动与竞赛中心](/events/)

一个官网链接、一份清晰的准备指南，或一次有帮助的复盘，都能为下一位参与者节省时间。

## 推荐一个活动

在项目仓库的 Issues 中选择“推荐活动或更新活动信息”提交建议。需要登录 GitHub，由维护者核验后收录。

请提供活动名称、官方链接、活动类型、面向对象，以及能核验时间的具体通知。未找到当届时间也可以推荐，明确写“待确认”即可。

## 修正过期信息

请写清本站页面地址、原来的信息、建议修改及最新公开来源。日期尽量包含年份、时区与具体时刻，避免只写“月底截止”。

## 分享参与经验

可以分享准备方法、工具使用、协作过程和复盘。注明参加的年份与届次，将个人经验与官方规则分开；不提供未公开题目、他人隐私或未经授权的材料。

## 用 Pull Request 直接贡献

熟悉 Git 的同学可以按[如何贡献](/about/contribute)修改活动详情页。列表会读取详情页中的活动字段生成卡片，无需另外维护一份列表。维护字段的说明见仓库 CONTRIBUTING.md 中的“活动与竞赛中心”。
