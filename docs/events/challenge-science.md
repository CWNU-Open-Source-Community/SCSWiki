# “挑战杯”全国大学生课外学术科技作品竞赛

围绕研究问题与科技作品，组织调研、实验验证和成果展示。

<EventDetails />

## 比赛简介

“挑战杯”全国大学生课外学术科技作品竞赛常被称为“大挑”，关注学生在课外研究与科技实践中形成的作品。它与“挑战杯”创业计划竞赛是并列项目，不能把两者的材料要求混为一谈。

从计算机专业的学习视角，可以围绕算法、系统、应用或交叉领域的问题开展研究与验证。作品不仅要说明做了什么，还要解释问题为何值得研究、已有工作有哪些不足、证据如何支持结论。

## 适合谁参与

适合愿意持续阅读、实验或调研的同学。已有课程设计或科研训练可以成为起点，但应核对参赛作品范围、完成时间与作者资格。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                         |
| ---------- | ---------------------------------------------------------------- |
| 明确问题   | 缩小研究范围，说明与已有方法或现有实践的关系。                   |
| 开展验证   | 设计实验、调研或原型测试，保留原始记录与可追溯过程。             |
| 整理作品   | 说明方法、结果、创新点和局限，并区分个人、团队及已有工作的贡献。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先阅读相关资料，与指导者讨论一个能够验证的小问题。
2. 设计可执行的研究计划，确定数据来源、对照方法和记录方式。
3. 边做边整理证据，不等到申报时才凭记忆补写过程。
4. 练习用简洁语言解释研究问题、关键结果和不足，核对作品类别与申报材料。

## 常见问题

### “大挑”和“小挑”能用同一份材料吗？

两者关注重点不同。学术科技作品应重视研究与技术证据，创业计划需要另行论证用户、价值和实施方式。

### 只有一个想法可以开始吗？

可以作为研究起点，但需要逐步形成实际工作和验证证据，不能把计划中的结果写成已经完成。

## 参与总结

“大挑”适合积累有持续性的研究经历。用清楚的问题和可靠证据支撑作品，比追求宏大的题目更便于做出扎实成果。
