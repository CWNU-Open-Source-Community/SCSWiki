# “挑战杯”全国大学生课外学术科技作品竞赛

围绕研究问题与科技作品，组织调研、实验验证和成果展示。

<EventDetails />

## 名称与收录范围

挑战杯官网分别列出课外学术科技作品竞赛与创业计划竞赛，两类赛事交替举办。通常所说“大挑”指科技作品竞赛，不应把“小挑”的届次和通知用于本赛。

依据：[挑战杯官网赛事介绍](https://www.tiaozhanbei.net/)。

## 准备建议

先明确研究问题和已有工作，再持续积累实验、调研与原创证据。具体申报类别、资格与校内推荐需查对应通知。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
