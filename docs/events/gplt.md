# 中国高校计算机大赛—团体程序设计天梯赛

以团队形式参与分梯级程序设计挑战，兼顾个人编程基础和队伍整体实力。

<EventDetails />

## 名称与收录范围

组委会通知中的全称为“中国高校计算机大赛-团体程序设计天梯赛”。本页使用中文破折号统一排版；GPLT、天梯赛为简称。它属于中国高校计算机大赛系列，不能与中国大学生计算机设计大赛合并。

依据：[第十一届赛前准备会通知（组委会 PDF）](https://gpltprod.ptausercontent.com/GPLT2b969d4e27f7a51035875be39884cc79.pdf)。

## 准备建议

从基础题开始限时练习，再逐步补充数据结构和算法。参赛队伍的组织、选拔和报名方式需查看本校正式通知。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
