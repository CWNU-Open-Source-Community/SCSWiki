# 中国高校计算机大赛—团体程序设计天梯赛

个人独立完成分梯级程序设计题，汇总团队成绩；从基础编程逐步走向算法训练。

<EventDetails />

## 比赛简介

团体程序设计天梯赛（GPLT）通过不同梯级的题目考查程序设计能力。题目从基础编程逐步延伸到数据结构、算法设计与较复杂的问题求解，因此同一场比赛可以观察到不同阶段选手的能力。

“团体”体现在成绩汇总和队伍整体表现上：选手在比赛中独立解题，并不是几个人围着同一台电脑共同写一份程序。日常训练则可以共同复盘，找出队伍在基础题稳定性和进阶题覆盖面上的短板。

## 适合谁参与

已经学过 C、C++ 或其他受支持语言，希望检验编程基础的同学可以从基础级往届题入门。学习过数据结构后，再逐步练习进阶题；校内选拔资格和组队办法需要另查本校通知。

## 主要内容与参与方式

| 环节或方向   | 重点了解                                                         |
| ------------ | ---------------------------------------------------------------- |
| 基础级（L1） | 熟悉输入输出、分支循环、数组、字符串等基本问题，重点是准确实现。 |
| 进阶级（L2） | 结合数据结构与常见算法组织解法，兼顾正确性和复杂度。             |
| 登顶级（L3） | 处理更复杂的建模与算法问题，需要更强的综合分析能力。             |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先独立完成一组基础级题目，记录读题、编码、调试各用了多久。
2. 按错误原因整理清单：边界条件、格式、整数范围、复杂度和知识缺口分别处理。
3. 补齐排序、集合、树与图等知识，再做混合题组；不要只反复练同一种题。
4. 赛前进行完整限时模拟，赛后每人讲清一题的思路、失败用例和改进方法。

## 常见问题

### “团体赛”能在比赛时互相讨论吗？

不要把团队汇总成绩理解成允许现场交流。应按当届纪律独立作答，训练期间再进行协作复盘。

### 刚学完 C 语言能开始吗？

可以先尝试基础级往届题。能稳定处理输入输出和边界情况，比直接追逐高难度题更适合作为第一步。

## 参与总结

天梯赛适合用来建立从语法到算法的分层训练习惯。一次模拟后的错题分类、独立完成率和调试时间，比单看总分更能帮助确定下一阶段学什么。
