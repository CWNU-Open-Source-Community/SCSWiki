# GitLink“确实开源”编程夏令营

在导师与社区支持下参与真实开源项目，通过持续贡献完成开发实践。

<EventDetails />

## 活动简介

GitLink“确实开源”编程夏令营（GLCC）围绕真实开源项目组织开发实践。CCF 的 2025 年介绍与总结体现了导师指导、项目开发及阶段评估等环节，不能把它仅理解为几次听课活动。

项目之间的语言、领域和任务规模不同。申请前先运行代码、理解任务并与导师交流，比只按项目名称判断难易程度更可靠。

## 适合谁参与

适合已有一定编程基础、希望体验社区项目协作的同学。应根据任务技术栈和个人时间选择项目，资格及评估条件则按当前届次核对。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                               |
| ---------- | ------------------------------------------------------ |
| 匹配项目   | 阅读技术要求、预期成果与贡献方式，评估自己的准备程度。 |
| 完成开发   | 拆分任务、提交改进并响应导师或维护者反馈。             |
| 阶段总结   | 以代码、测试和记录说明进展，及时调整未完成部分的计划。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 选择一个项目，完成环境搭建并记录卡点和解决办法。
2. 阅读目标模块与已有问题，尝试提出一个具体、可验证的改进。
3. 把开发目标分成小阶段，每个阶段都定义能够展示的结果。
4. 持续整理测试和评审记录，结项时说明实际完成内容与剩余问题。

## 常见问题

### 和 CCF 开源创新大赛相同吗？

不是。GLCC 是导师指导的项目实践活动，开源创新大赛有独立赛道与竞赛评审安排。

### 导师会逐行教我从零写项目吗？

不能这样预期。应先具备任务需要的基础，主动尝试，再带着明确问题交流。

## 参与总结

GLCC 适合建立持续贡献的工作习惯。把过程记录与可运行成果一起留下，有助于在活动结束后继续参与项目维护。
