# 全国大学生信息安全竞赛

了解信息安全作品设计与创新实践能力两类赛道，培养安全分析与工程能力。

<EventDetails />

## 名称与收录范围

2026 年官网发布第十九届竞赛公告，并分别列出作品赛和创新实践能力赛通知。两条赛道的日程与形式不能互相替代；某一赛道的联合赛事名称也不能用于重命名整个竞赛。

依据：竞赛官方公告列表。

## 准备建议

作品方向先明确安全问题、实现方案与验证方法；实践方向使用授权靶场训练。参赛资格和评测要求分别查阅所选赛道公告。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
