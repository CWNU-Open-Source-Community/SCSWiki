# 百度之星程序设计大赛

以程序设计与算法解题为主要内容，适合进行个人限时编程训练。

<EventDetails />

## 比赛简介

百度之星程序设计大赛以程序设计和算法问题求解为核心。公开的历届程序设计赛资料可用于了解题目风格、评测方式与训练方向。

本页关注程序设计赛事。百度之星历史页面中也可能出现开发者相关活动，不能仅凭品牌名称把应用作品赛、招聘活动与算法赛混在一起。

## 适合谁参与

适合已经掌握基础数据结构、想进一步练习综合算法题的同学。若目前写程序还经常卡在语法和输入输出，可以先完成课程练习，再尝试历届题。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                           |
| ---------- | ------------------------------------------------------------------ |
| 理解问题   | 分析约束和数据范围，找出可计算的模型。                             |
| 实现算法   | 在时间与空间限制内完成程序，并处理极端输入。                       |
| 阶段安排   | 公开往届赛程可供了解形式，当前轮次、资格和晋级办法须另查当届说明。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 从较容易的往届题开始，写出暴力解法并估算为何需要优化。
2. 练习从朴素方法推导更高效算法，保留关键的正确性说明。
3. 对拍或构造小规模用例，定位实现错误与算法错误的区别。
4. 限时完成混合题组，赛后补题时重新独立实现，而不只阅读题解。

## 常见问题

### 参加比赛等于参加百度招聘吗？

本页介绍的是程序设计赛事。招聘、实习或其他活动应单独查看对应通知，不作关联承诺。

### 历届规则还能直接用吗？

适合用来理解历史形式与题型，不能替代当届参赛资格、语言、平台和晋级规定。

## 参与总结

适合把百度之星往届题作为算法进阶训练素材。重点记录从题目约束到算法选择的过程，而不只是记住某一题用了什么模板。
