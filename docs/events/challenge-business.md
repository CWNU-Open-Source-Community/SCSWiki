# “挑战杯”中国大学生创业计划竞赛

围绕真实需求和创业方案，检验用户价值、实施条件与团队计划。

<EventDetails />

## 比赛简介

“挑战杯”中国大学生创业计划竞赛常被称为“小挑”，围绕技术、产品或服务形成创业计划。它与课外学术科技作品竞赛的侧重点不同，需要说明服务谁、解决什么问题以及如何持续实施。

对技术团队而言，能写出系统只是起点，还应验证目标用户是否确实需要它，分析成本、竞争方案和推广方式。计划中的估算要与已经发生的事实明确区分。

## 适合谁参与

适合对产品、创新实践和跨专业协作感兴趣的同学。技术、设计、运营与调研能力可以互补，建议先从能够接触到的真实需求做起。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                   |
| ---------- | ---------------------------------------------------------- |
| 需求与用户 | 通过可追溯的访谈、观察或数据理解问题，避免只依据个人想象。 |
| 产品与价值 | 说明方案提供的价值、与替代方案的差别及实现条件。           |
| 计划与证据 | 组织成本、资源、实施步骤和验证结果，明确假设与风险。       |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 确定一个具体用户群，记录问题频率、现有解决方法与不便。
2. 做小规模原型或服务试验，观察用户是否愿意使用，而不只询问是否喜欢。
3. 依据实际信息估算资源与成本，注明数据来源和不确定条件。
4. 把计划书与真实进展对齐，练习解释最关键的假设和下一步验证。

## 常见问题

### 只有技术原型，没有用户反馈怎么办？

先补充需求验证。找合适的潜在用户体验，并记录反馈如何影响方案，而不是凭空增加市场规模数字。

### 参加就必须先成立公司吗？

不能据此下结论。不同组别的条件可能不同，应核对当届规则，再决定是否符合申报要求。

## 参与总结

“小挑”的准备应围绕需求与实施证据展开。即使项目尚早，也可以清楚说明已经验证了什么、还存在哪些假设。
