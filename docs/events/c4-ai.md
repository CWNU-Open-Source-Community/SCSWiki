# 中国高校计算机大赛—人工智能创意赛

围绕人工智能应用与创意作品，探索从技术原型到场景验证的完整过程。

<EventDetails />

## 比赛简介

中国高校计算机大赛—人工智能创意赛强调人工智能及相关技术在具体场景中的创新应用。2026 年官方页面设置鸿蒙创新赛道与昇腾 AI 赛道，两者的技术要求需要分别查看。

参赛准备应从“为谁解决什么问题”出发，再选择模型、应用框架和设备。除了模型效果，还应考虑用户操作、系统稳定性与演示过程。

## 适合谁参与

适合对 AI 应用、移动应用或软硬件协同感兴趣的同学。可以由熟悉开发、模型和交互设计的成员协作，先做一个范围清楚的原型。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                             |
| ---------- | ---------------------------------------------------- |
| 场景与创意 | 明确目标用户、使用条件及现有方案的不足。             |
| 赛道实现   | 依据所选赛道的技术和平台约束，完成核心功能。         |
| 效果验证   | 用真实可复现的例子展示效果，说明失败情况及适用范围。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先确认赛道，列出必须使用的技术、允许数据与交付要求。
2. 设计一个最小使用流程，让用户能够完成一项具体任务。
3. 将 AI 能力接入应用，测试延迟、异常输入和结果不可靠时的处理。
4. 准备可现场运行的演示和技术说明，明确自研、开源与第三方服务各自的部分。

## 常见问题

### 只训练一个模型就够了吗？

要看所选赛道的成果要求。创意应用通常还需要说明使用场景和实现方式，不能只展示一个孤立指标。

### 一定使用同一套开发平台吗？

不同赛道可能有不同约束，鸿蒙应用与昇腾 AI 方向不能混用准备清单。

## 参与总结

把创意落实为可使用的原型，再用证据说明它在哪些条件下有效。清楚的场景与完整体验，是技术展示的重要支撑。
