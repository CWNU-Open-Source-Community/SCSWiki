# 全国大学生电子设计竞赛

围绕电子系统设计、嵌入式开发与测试，完成软硬件结合的工程作品。

<EventDetails />

## 比赛简介

全国大学生电子设计竞赛强调理论设计与实际制作的结合，围绕电子系统任务开展设计、调试和测试。除了程序，还需要考虑电路、供电、信号和器件在真实环境中的表现。

全国竞赛、赛区安排和不同专题赛的赛题、平台及时间并不完全相同。例如公开的 2026 年专题赛通知给出了各自的技术和制作要求，不能把某一专题规则当作所有电赛的通用规则。

## 适合谁参与

适合愿意动手进行电路与嵌入式实践的同学。参与前应评估实验条件和团队基础，先掌握安全操作及基本仪器使用，再扩大项目难度。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                             |
| ---------- | ---------------------------------------------------- |
| 方案设计   | 把任务指标拆成电源、采集、处理、控制和输出等模块。   |
| 制作调试   | 根据设计完成电路和固件，逐层检查信号与接口。         |
| 测试报告   | 用测量数据说明系统是否满足指标，并记录误差与稳定性。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 练习万用表、示波器和电源等设备的规范使用，熟悉常见故障定位方法。
2. 先实现一个小系统，例如传感器采集与显示，并保存原理图和测试记录。
3. 按模块独立验证后再联调，预留器件替换、接线和供电问题的排查时间。
4. 围绕指标进行多次测量，写清测试条件，避免只记录一次理想结果。

## 常见问题

### 计算机专业只负责写代码可以吗？

可以侧重嵌入式软件或控制实现，但仍需理解硬件接口、信号和测量条件，才能有效协作。

### 需要提前购买整套器材吗？

应先明确赛项、已有实验条件和训练目标，再与指导团队确认必要器材，避免按未经核实的清单采购。

## 参与总结

电子设计训练能把理论与真实设备连接起来。清楚的模块接口、规范的测量和持续的联调记录，有助于提高系统可靠性。
