# LFX Mentorship

通过 Linux Foundation 生态中的导师项目，参与开源技术实践。

<EventDetails />

## 名称与收录范围

LFX Mentorship 是 Linux Foundation 提供的开源导师计划工具与项目入口，不是统一赛制的竞赛。各项目的申请窗口、技术要求与投入安排分别发布。

依据：LFX Mentorship 项目平台。

## 准备建议

根据技术方向查看项目和导师要求，先阅读社区贡献规范、运行项目并积累公开贡献记录，再准备申请材料。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
