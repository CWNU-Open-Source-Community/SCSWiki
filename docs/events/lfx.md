# LFX Mentorship

通过 Linux Foundation 生态中的导师项目，参与开源技术实践。

<EventDetails />

## 活动简介

LFX Mentorship 是 Linux Foundation 提供的开源导师计划平台，连接项目维护者、导师和希望参与开源的贡献者。具体工作由项目决定，并不意味着所有项目都在开发 Linux 内核。

准备时应逐个查看项目任务、前置技能和时间安排。一个有清楚边界的项目计划，可以帮助申请者评估自己能否持续投入并完成预期成果。

## 适合谁参与

适合希望接触国际开源项目、已经具备相应开发基础的同学。不同项目可能需要系统、云原生、工具或其他领域知识，应按项目判断。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                           |
| ---------- | -------------------------------------------------- |
| 项目选择   | 比较任务目标与自身基础，不只看组织知名度。         |
| 申请准备   | 了解代码库、贡献流程和所需材料，提出具体工作计划。 |
| 导师协作   | 按项目约定沟通、实现、验证和评审，保持进展透明。   |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 阅读一个候选项目的文档和贡献说明，尝试跑通开发环境。
2. 追踪与目标任务相关的 Issue 和评审，了解维护者关心的问题。
3. 完成一个小贡献或技术验证，用事实判断项目是否适合自己。
4. 安排稳定的开发与沟通时间，保留测试、讨论及阶段总结。

## 常见问题

### 只能做 Linux 内核吗？

不能这样理解。平台包含不同开源项目，应查看各项目的技术方向。

### 所有项目同一时间报名吗？

项目和批次可能不同，申请窗口与时间投入要求需要逐项确认。

## 参与总结

LFX Mentorship 的价值在于与项目维护者一起完成真实任务。优先选择能够理解、持续参与并验证成果的项目。

## 名称与收录范围

LFX Mentorship 是 Linux Foundation 提供的开源导师计划工具与项目入口，不是统一赛制的竞赛。各项目的申请窗口、技术要求与投入安排分别发布。
