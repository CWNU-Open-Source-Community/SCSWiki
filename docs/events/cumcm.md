# 全国大学生数学建模竞赛

把现实问题转化为数学模型，结合编程计算、结果验证与论文表达完成团队作品。

<EventDetails />

## 比赛简介

全国大学生数学建模竞赛要求参赛者围绕实际问题进行分析，建立数学模型，并用计算、数据和论文说明解决方案。问题通常没有唯一固定的解题路径，合理的假设与验证过程非常重要。

建模并不等于堆叠复杂公式。读懂问题、选择适当方法、说明适用条件以及检验结果，共同构成一份完整的建模工作。

## 适合谁参与

适合愿意结合数学、编程和写作解决开放问题的同学。队员可以各有侧重，但最好都理解整体问题与关键假设，避免模型、代码和论文彼此脱节。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                 |
| ---------- | -------------------------------------------------------- |
| 问题抽象   | 明确目标、约束、变量与假设，识别可用数据和缺失信息。     |
| 模型求解   | 选择适当的数学或统计方法，并通过程序计算和分析结果。     |
| 论文与验证 | 说明方法、结果、敏感性和局限，使读者能够理解并复核过程。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 选择一道往届题，先用自己的话列出每个问题要交付什么结果。
2. 用简单基线模型获得初步结果，再判断是否需要更复杂的方法。
3. 让模型、代码、图表和文字同步更新，保留数据处理步骤与参数。
4. 完成一次从选题到提交的模拟，留出检查假设、引用、附件和排版的时间。

## 常见问题

### 数学成绩好就一定能做好建模吗？

数学基础有帮助，但还需要问题理解、计算实现、合作与表达。可以通过完整的小项目补齐这些环节。

### AI 工具和外部材料可以怎样使用？

须阅读当届关于工具、引用和诚信的具体规定，并如实记录使用情况，不能直接套用往届经验。

## 参与总结

建模训练的收获是把现实问题转化为可分析、可计算、可解释的模型。复盘时关注假设是否合理、验证是否充分，而不只看最终数值。
