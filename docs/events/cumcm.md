# 全国大学生数学建模竞赛

把现实问题转化为数学模型，结合编程计算、结果验证与论文表达完成团队作品。

<EventDetails />

## 名称与收录范围

2026 年组委会通知标题使用“2026高教社杯全国大学生数学建模竞赛”。“高教社杯”为该届标题中的冠名，本目录保留稳定赛事名称。国内赛与美国大学生数学建模竞赛不是同一赛事。

依据：[2026 高教社杯全国大学生数学建模竞赛通知](https://www.mcm.edu.cn/html_cn/node/d6fd7a0ee8f3a3d525e30af1c365fcec.html)。

## 准备建议

练习建模、编程和写作分工，重视模型假设、检验与引用。参赛前阅读当届关于 AI 工具和学术规范的专门规定。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
