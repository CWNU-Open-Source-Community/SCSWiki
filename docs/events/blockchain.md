# CCF大学生区块链安全技术与创新应用竞赛

结合区块链安全与应用设计，完成技术方案、实现和测试验证。

<EventDetails />

## 比赛简介

CCF 大学生区块链安全技术与创新应用竞赛关注区块链相关的安全技术和应用方案。公开章程要求参赛者围绕场景组织作品，并用技术文档、代码和测试材料支持成果说明。

选题应先回答为何需要区块链：参与方之间有什么信任或协作问题，现有数据库方案为何不足。随后再考虑权限、数据一致性、隐私保护和系统运行成本。

## 适合谁参与

适合已有软件开发基础、愿意学习分布式系统和安全机制的同学。可以先从规模较小的多方协作原型开始，避免只展示概念和界面。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                   |
| ---------- | ---------------------------------------------------------- |
| 问题与方案 | 确定参与方、信任边界、数据流程和需要解决的具体问题。       |
| 技术实现   | 按照作品目标实现必要模块，说明链上与链下的责任划分。       |
| 验证与展示 | 用正常和异常用例检查安全性、性能及可用性，整理可复现材料。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先写一页场景说明，对比采用普通数据库与区块链的优缺点。
2. 完成最小原型，明确身份、权限、交易或数据流转的约束。
3. 设计异常输入、权限越界、重复请求等测试，记录限制而不是只展示成功流程。
4. 整理部署步骤、源码说明和测试报告，让他人能重现主要结果。

## 常见问题

### 这是虚拟币交易比赛吗？

本页介绍的是区块链安全技术与创新应用竞赛，学习重点是系统和应用设计。

### 只画架构图能作为完整成果吗？

需按章程与赛项要求准备代码、说明及验证材料，不能把尚未实现的设计写成已经完成的功能。

## 参与总结

先证明问题真实存在，再说明区块链方案为何合适。一个范围清楚、能够验证的原型，比功能庞大却无法复现的方案更便于评审和学习。
