# SCSWiki 开源共建

从修正文档、补充公开来源开始，让你的第一份贡献帮助下一位同学。

<EventDetails />

## 这是什么

SCSWiki 是学生维护的非官方知识库。仓库接受内容纠错、来源补充和工程改进；这里提供的是长期贡献入口，不是已经启动的限时比赛。

## 适合谁

希望尝试开源协作的同学。不要求先会编程：能描述一个问题、核实一个公开来源，就可以开始。

## 如何参与

1. 在本站找到一个可以改进的页面，例如过期链接、遗漏的说明或不清楚的步骤。
2. 查阅公开来源，记录页面地址、问题和建议。避免加入个人隐私与未经授权的材料。
3. 通过仓库 Issue 提交建议，或按照[如何贡献](/about/contribute)创建 Pull Request。
4. 根据维护者反馈完善内容，合并后检查页面效果。

## 出发前的准备

- [Git 入门](/development/git-basics)：了解版本管理和基础协作。
- [可信度与内容边界](/about/trust)：区分学校正式信息与学生经验。

## 时间与成果

没有统一报名截止时间，也不设自动发放的证书或奖项。实际任务与合并情况以仓库记录为准。首次贡献建议选择范围清晰的小改动。
