# SCSWiki 开源共建

从修正文档、补充公开来源开始，让你的第一份贡献帮助下一位同学。

<EventDetails />

## 活动简介

SCSWiki 开源共建是围绕本站内容与代码持续进行的协作。你可以修正一个错误、补充可靠来源、改善页面体验，或整理一份能帮助后来同学的学习经验。

贡献不以代码量衡量。对知识库而言，准确、可核验、尊重隐私且便于维护的内容同样重要。提交修改后，还需要回应评审意见，让变更适合长期保留。

## 适合谁参与

适合愿意整理知识或帮助改进本站的同学。不会编程也可以从文字纠错和内容建议开始；涉及组件或脚本时，再补充相应开发基础。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                                       |
| ---------- | -------------------------------------------------------------- |
| 内容贡献   | 区分正式信息与个人经验，补齐公开来源和适用范围。               |
| 体验改进   | 报告清楚的复现步骤，或完成一处范围明确的排版、导航和交互修复。 |
| 工程协作   | 按贡献指南修改、验证并提交变更，及时回应维护者反馈。           |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先阅读贡献指南，选一个能明确说明完成条件的小问题。
2. 收集可靠公开依据；涉及个人经验时注明适用情境，不写成学校政策。
3. 只修改与问题相关的内容，检查隐私、图片授权和页面内部链接。
4. 本地预览并按仓库要求运行检查，在提交说明中写清原因、改动和验证。

## 常见问题

### 没有 Git 基础也能参与吗？

可以先通过贡献入口提出内容建议或纠错，熟悉流程后再学习直接修改文件。

### 提交后一定会合并吗？

不一定。维护者会结合内容可靠性、范围和可维护性评审，可能需要补充证据或调整实现。

## 参与总结

从一个小而明确的问题开始，完成修改、验证和反馈的全过程。持续提高内容可信度，是知识库共建最重要的目标。
