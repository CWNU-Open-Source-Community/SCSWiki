# 开源操作系统训练营

从 Rust 与操作系统基础出发，通过实验逐步参与 rCore 等开源系统实践。

<EventDetails />

## 活动简介

开源操作系统训练营通过课程与实验帮助学习者理解并实现操作系统。2026 春夏季安排从 Rust 和系统原理导学开始，进入 rCore 实验、组件化系统以及项目实践等阶段。

它是学习与实践活动，不等同于操作系统设计赛。完成课程可以为后续系统开发或参赛建立基础，但不同阶段的学习、评测和晋级要求应分别查看。

## 适合谁参与

适合对系统软件感兴趣、愿意持续写代码和调试的同学。已有一门语言基础会更容易进入；开始前可先补充 Linux、Git 和操作系统核心概念。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                               |
| ---------- | ------------------------------------------------------ |
| 语言与工具 | 学习 Rust 的所有权等基础，熟悉 Linux 与开发工具。      |
| 内核实验   | 通过 rCore 等实验理解进程、内存、文件系统和系统调用。  |
| 项目实践   | 在完成必要前置学习后，参与组件或真实项目的设计与开发。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先跑通训练营指定环境，完成简单 Rust 练习并记录工具版本。
2. 每个实验先理解执行路径，再修改代码，避免只针对测例拼凑答案。
3. 用调试日志说明问题出现在哪一层，遇到卡点时提交最小复现。
4. 完成阶段后整理设计笔记和测试结果，再根据基础进入项目实践。

## 常见问题

### 错过集中授课就完全不能学习了吗？

2026 春夏季页面说明可继续报名和观看回放，但同步课程与实时答疑条件不同，应查看当前入口安排。

### 通过所有测例就代表理解了原理吗？

测例能帮助验证实现，仍建议解释关键路径、边界条件和设计取舍，用自己的话写出实验总结。

## 参与总结

训练营适合循序渐进建立底层开发能力。把“能运行”进一步变成“能解释、能定位、能修改”，才便于进入真实系统项目。
