# CCF开源创新大赛

通过项目贡献、任务挑战或案例教学参与开源，把成果放到真实社区中检验。

<EventDetails />

## 名称与收录范围

中国计算机学会发布的第八届通知使用“CCF开源创新大赛”，包含开源项目贡献、开源任务挑战、开源案例教学方向。该赛事与 GitLink“确实开源”编程夏令营不同，分别收录。

依据：CCF 第八届开源创新大赛通知。

## 准备建议

先挑选与现有技术栈匹配的赛题，阅读交付与评审标准。使用公开仓库记录贡献过程，并确认代码和材料的许可。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
