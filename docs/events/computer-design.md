# 中国大学生计算机设计大赛

围绕软件应用、人工智能、物联网和数字媒体等方向，完成可展示的计算机作品。

<EventDetails />

## 比赛简介

中国大学生计算机设计大赛围绕不同类别的计算机应用与设计作品开展。软件应用、数字媒体等方向对技术、表达和成果形式的要求不同，应从当届类别说明中选择适合的入口。

它与“中国高校计算机大赛”不是同一个名称，也不等于限时算法答题。备赛需要围绕明确主题形成完整作品，并清楚说明使用场景、实现过程和团队贡献。

## 适合谁参与

适合希望结合编程、设计和领域知识完成作品的同学。可以从课程项目中发现值得继续完善的问题，但需要核对题目主题、作品类别和原创性要求。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                               |
| ---------- | ------------------------------------------------------ |
| 确定类别   | 先看作品类型与提交格式，再安排技术路线和分工。         |
| 完成作品   | 让功能或创意服务于明确目标，保留设计迭代与实现过程。   |
| 组织展示   | 用操作演示、效果图和说明材料解释成果，并说明素材来源。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 阅读目标类别的规则，列出主题限制、作品形式与材料清单。
2. 用草图、原型或小样验证核心想法，再决定是否扩展项目范围。
3. 每次迭代都检查作品是否更容易理解或使用，不只增加页面和功能。
4. 准备脱离开发电脑也能展示的版本，核查字体、图片、音乐和数据的授权。

## 常见问题

### 会做网页可以参加哪一类？

要看网页承载的作品目标及当届类别定义，不能仅凭使用了某种技术确定类别。

### 和天梯赛是同一个大赛的赛项吗？

不是。本页是中国大学生计算机设计大赛；天梯赛属于中国高校计算机大赛系列。

## 参与总结

先选准作品类别，再把创意做成可体验、可解释的成果。技术实现与表达应相互支撑，避免材料描述远超实际完成度。

## 名称与收录范围

官网名称为“中国大学生计算机设计大赛”，常用缩写 4C。它与“中国高校计算机大赛”（含天梯赛、人工智能创意赛等）是不同赛事。本页不把二者混称为“计算机大赛”。
