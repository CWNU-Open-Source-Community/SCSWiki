# 中国大学生计算机设计大赛

围绕软件应用、人工智能、物联网和数字媒体等方向，完成可展示的计算机作品。

<EventDetails />

## 名称与收录范围

官网名称为“中国大学生计算机设计大赛”，常用缩写 4C。它与“中国高校计算机大赛”（含天梯赛、人工智能创意赛等）是不同赛事。本页不把二者混称为“计算机大赛”。

依据：中国大学生计算机设计大赛：大赛简介。

## 准备建议

先确定当届作品类别，围绕真实问题完成原型、说明文档和演示。参赛作品需符合相应原创性、素材与提交规则。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
