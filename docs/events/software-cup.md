# “中国软件杯”大学生软件设计大赛

围绕企业和行业赛题开发软件作品，练习需求分析、实现、测试与成果演示。

<EventDetails />

## 名称与收录范围

第十五届通知使用“‘中国软件杯’大学生软件设计大赛”。本次检索官网正文访问不稳定，名称与赛事方向交叉参考高校公开转载；其中的校内安排仅适用于发布学校，不适用于西华师范大学。

依据：[第十五届赛事通知（西南交通大学公开转载）](https://jwc.swjtu.edu.cn/vatuu/WebAction?newsId=7B02FB387DCB9620&setAction=newsDetail&viewType=web)。

## 准备建议

按所选赛题要求搭建最小可演示版本，再完善测试、文档与演示材料。A、B 组及专项赛道适用对象须核对当届规则。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
