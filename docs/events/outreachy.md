# Outreachy

面向符合资格的申请者提供远程开源实习，涵盖编程、文档、设计等贡献。

<EventDetails />

## 活动简介

Outreachy 提供远程开源实习，支持在所在技术行业中面临代表性不足、系统性偏见或歧视的参与者。项目不局限于编程，也可能涉及文档、设计、研究或数据等工作。

申请通常包含资格审核、项目贡献与最终申请等环节。它有明确的资格和时间投入要求，不能把它当作所有学生都能直接报名的通用暑期活动。

## 适合谁参与

适合符合当届资格、能满足时间安排并愿意持续参与开源协作的申请者。应先阅读申请指南，尤其核对学习、工作或其他承诺与项目周期的关系。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                           |
| ---------- | -------------------------------------------------- |
| 资格确认   | 根据个人实际情况如实阅读和回答申请要求。           |
| 项目贡献   | 在规定阶段了解项目并完成真实贡献，记录沟通和成果。 |
| 远程实践   | 与导师协作推进项目，按照约定整理进展和交付结果。   |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先核对资格和时间要求，确认能够投入后再选择具体项目。
2. 阅读项目任务与贡献说明，从范围明确的小工作开始。
3. 记录每次贡献的目标、反馈和改进，不用提交数量代替质量。
4. 在最终申请中说明已经了解的工作、可行计划和需要继续学习的内容。

## 常见问题

### 一定是编程项目吗？

不是。官方介绍包含文档、设计、研究等多种工作，技能要求应以具体项目为准。

### 入选后是否保证获得支持组织的工作？

官方说明实习不与支持组织的就业机会绑定，应把项目经历与后续招聘分开理解。

## 参与总结

Outreachy 的准备顺序是先确认资格与时间，再通过真实贡献理解项目。选择能发挥自身能力并持续协作的工作，比广泛投递更有意义。

## 名称与收录范围

Outreachy 面向在技术行业受到代表性不足或系统性偏见等影响、且符合其资格政策的人群。它是有资格审核的开源实习计划，不是所有在校生均可报名的比赛；不同轮次的申请、贡献期与实习期分开安排。
