# Outreachy

面向符合资格的申请者提供远程开源实习，涵盖编程、文档、设计等贡献。

<EventDetails />

## 名称与收录范围

Outreachy 面向在技术行业受到代表性不足或系统性偏见等影响、且符合其资格政策的人群。它是有资格审核的开源实习计划，不是所有在校生均可报名的比赛；不同轮次的申请、贡献期与实习期分开安排。

依据：[Outreachy 官方活动与资格入口](https://www.outreachy.org/)。

## 准备建议

先阅读当轮完整资格规则并核对可投入时间，再评估项目。通过初步资格审核后的贡献阶段，不等于已获实习录取。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
