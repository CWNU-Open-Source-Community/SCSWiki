# Google Summer of Code 2026

在导师指导下参与开源项目，与全球社区协作，积累真实开发经验。

<EventDetails />

## 活动简介

Google Summer of Code（GSoC）是面向开源新贡献者的全球线上项目。贡献者向参与的开源组织提出项目计划，在导师指导下开展开发，并按项目安排接受评估。

GSoC 不是 Google 的招聘或雇佣计划，也不只面向在校学生。年龄、开源经验等资格应阅读当届官方规则；实际技术工作由不同开源组织和项目决定。

## 适合谁参与

适合已经能独立开发、希望参与国际开源社区且能安排持续时间的同学。英语的主要用途是阅读文档、解释方案和异步交流，不必追求复杂表达。

## 主要内容与参与方式

| 环节或方向 | 重点了解                                               |
| ---------- | ------------------------------------------------------ |
| 了解组织   | 阅读项目想法、贡献指南与历史讨论，选择真正理解的方向。 |
| 提出计划   | 说明目标、技术方案、里程碑、验证方法和可投入时间。     |
| 开发协作   | 持续提交成果、回应评审并沟通进展，按约定整理项目结果。 |

## 如何准备

以下是本站的学习建议，不是主办方附加的参赛条件。

1. 先运行目标项目并尝试一个范围小的修复或文档改进。
2. 阅读组织公开沟通规则，提问时写清已尝试的方法和具体卡点。
3. 与导师讨论提案范围，将必要成果和可选扩展分开安排。
4. 准备周进展与测试记录，让异步协作中的状态清楚可见。

## 常见问题

### 入选意味着成为 Google 实习生吗？

不是。官方 FAQ 明确区分 GSoC 与 Google 雇佣或实习关系，应准确描述自己的开源项目经历。

### 需要在申请前完成整个项目吗？

不需要把提案项目提前全部做完，但应证明理解代码库与问题，并提出可执行的工作计划。

## 参与总结

GSoC 的核心收获是与真实开源组织持续协作。即使尚未申请或没有入选，前期贡献和讨论也可以成为继续参与社区的起点。
