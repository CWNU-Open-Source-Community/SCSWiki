# 国际大学生程序设计竞赛（ICPC）

三人团队协作解决算法问题，沿区域赛等赛事体系逐级参与挑战。

<EventDetails />

## 名称与收录范围

ICPC 官方英文全称为 International Collegiate Programming Contest。其赛事体系包括地区及更高层级赛事，不能用世界总决赛日程代表所有区域赛。历史资料中的 ACM-ICPC 可用于检索，不作为当前名称。

依据：ICPC 2026 World Finals：About。

## 准备建议

先建立算法和数据结构基础，再开展三人共用比赛资源的团队训练。查看拟参加赛站的资格规则及学校组队要求。

以上准备建议由 SCSWiki 整理，不是主办方附加的参赛条件。

## 参与前核对

本页收录常设入口。“查看当届通知”不表示当前正在报名；具体资格、赛项、时间与交付要求以当届官方规则为准。学校组织报名、费用、奖项认定与推荐名额需另查本校公开正式通知。
